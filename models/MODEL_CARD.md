# Model Card

The trained Layer 3 model (RoBERTa-base fine-tuned for prompt injection
classification) is hosted on Hugging Face, not in this GitHub repository,
to avoid Git LFS bandwidth limits on large binaries.

**Model:** https://huggingface.co/shivateja1253/rag-pif-roberta

Includes the production checkpoint plus two documented experimental
checkpoints (see the model card there for full evaluation numbers and
the reasoning behind why each experimental checkpoint was not promoted
to production).
